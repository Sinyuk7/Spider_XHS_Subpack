## 项目说明


🚀 如何使用(macOS)：
每次运行项目时，请先激活环境：


# 激活Python虚拟环境
source spider_xhs_env/bin/activate

# 激活Node.js环境  
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
nvm use 18

# 然后运行你的Python脚本
python main.py
